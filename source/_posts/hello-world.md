这是 **vin-place** 的第一篇文章。

之所以再次开始写博客，是因为我意识到，许多想法如果不落在某个具体的地方，就会像风一样飘过去。一个安静、属于自己的小角落，似乎正好可以解决这个问题。

## 这里会写些什么

- 写代码时遇到的有意思的问题
- 一些读到、看到、想到的零碎念头
- 偶尔出门时拍下的照片

## 为什么用 Hexo

静态博客最大的好处是 **没有数据库、不需要维护服务器**。所有文章只是仓库里的 Markdown 文件，可以随时迁移、随时备份。配合 GitHub Pages，整套部署几乎是零成本的。

> 静态生成的博客只需关心自己的博客文章文件即可，同时 Markdown 格式又允许使用不同的设备随时编写、记录。

希望这个小地方可以长久地存在下去。
