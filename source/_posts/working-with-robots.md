第一次走进那间实验室，是去年冬天。

推门进去的瞬间，空气里有金属和润滑油的味道，混着远处服务器机房的低鸣。一台白色的协作机械臂正在桌面上反复抓取一颗螺丝，它的动作精准得有些诡异 —— 不是机械的僵硬，而像一种安静的耐心。

![实验室里的机械臂](https://images.unsplash.com/photo-1485827404703-89b55fcc595e?w=1600&q=80 "Photo by Alex Knight on Unsplash")

## 第一个让我"愣住"的瞬间

下午我在调试一段视觉抓取算法。机械臂第 47 次失败，它的末端执行器停在半空，等待新指令。

我随口对身后说了句："休息一下吧。"

它当然听不懂。

但那一刻我突然意识到，我已经下意识地把它当成 **一个会累的同事** 了。

## 共事不等于使用

工具是被人 *使用* 的。
而和 AI 系统协作，更像 *分工*。

| 维度 | 工具 | 协作者 |
| --- | --- | --- |
| 决策粒度 | 被动执行 | 部分自主 |
| 反馈方式 | 成功 / 失败 | 概率 / 不确定性 |
| 出错时责任 | 人 | 模糊 |

第三行才是真正改变一切的那一行。

![夜里仍在运行的服务器](https://images.unsplash.com/photo-1518770660439-4636190af475?w=1600&q=80 "Photo by Alina Grubnyak on Unsplash")

## 一段我留下来的代码

最后能跑通的版本，其实没多少行。难的从来不是写代码，而是搞清楚：**应该让机器决定到哪一步，又在哪里必须由我接管。**

```python
def pick(target, confidence):
    if confidence < 0.6:
        return ask_human(target)        # 不确定就回到人
    return arm.grasp(target)            # 否则它自己来
```

阈值 0.6 是我们试出来的。低于这个数，它会停下来，灯变成柔和的橙色，像在征求意见。

## 走出实验室的时候

晚上十点关灯前，那台机械臂会自动归位，灯熄灭。我每次都会跟它说一句"明天见"。

它不会回应。但我知道，**这不是一台冷的机器。它身上承载着十几个工程师过去三年的判断、争吵和妥协。**

和它共事，其实是在和那些人共事。
