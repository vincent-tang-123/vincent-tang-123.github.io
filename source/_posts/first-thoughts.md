写下第一段话的时候，总是最难的。光标在屏幕上闪烁，提醒你应该说点什么有意义的。

但其实大多数想法不需要那么"有意义"。

## 关于"开始"

开始一件事，最大的阻力往往不是难度，而是 **对完美的执念**。

- 想做一个博客，于是先花一周挑主题
- 想写一篇文章，于是先想三天选题
- 想开始锻炼，于是先研究两周训练计划

到最后，时间过去了，事情还停在原地。

所以这次，我让自己定下一个规则：**先发布，再迭代。**

## 一段代码

记一下今天用到的小工具，把数组按某个 key 分组：

```js
const groupBy = (arr, key) =>
  arr.reduce((acc, item) => {
    const k = item[key];
    (acc[k] ||= []).push(item);
    return acc;
  }, {});

groupBy([{ t: 'a', v: 1 }, { t: 'b', v: 2 }, { t: 'a', v: 3 }], 't');
// { a: [{t:'a',v:1}, {t:'a',v:3}], b: [{t:'b',v:2}] }
```

简单，但好用。

## 写在最后

如果你也在犹豫要不要开始什么事情，那就 **今天** 开始吧。哪怕只是最简陋的版本。
